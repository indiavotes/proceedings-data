debates-rs

This Cloudflare Pages project will serve the debates-rs split of the IndiaVotes proceedings-data repo: Indian parliamentary debates-rs records (titles, metadata, derived search indexes, text bundles).

First scrape hasn't landed yet. Once it does, the production endpoints under this domain will be:

  • /meta.json — corpus identity + totals + freshness
  • /reports-meta.json — record-shard manifest
  • /reports-debates-NN.json — sharded records (newest-first)
  • /manifest.json, /audit.json, /texts-NN.json
